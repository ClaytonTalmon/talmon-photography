Publishing connection

This editor stays on your computer. Publishing updates your website through your GitHub account. Your access token is kept only in this window and cleared when you close it.

  1. Open GitHub’s fine-grained token settings.
  2. Select only ClaytonTalmon/talmon-photography.
  3. Under repository permissions, set Contents: Read and write. Choose an expiration date and generate the token.
  4. Paste it here. Never send it in a message.
